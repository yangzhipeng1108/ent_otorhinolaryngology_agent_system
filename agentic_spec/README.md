# Agentic Spec Library

本目录收录Agentic Craft Alignment（ACA）的宪法级规范，定义AI与人工协作时必须遵守的
不变量、分级执行宪章以及命名权威体系。所有工程级操作文档在引用ACA条款时，应从这里
确认约束来源。

## 文档速览
- **SPEC_ACA_CORE_PRINCIPLES.md**：ACA四大不变量、PDCA契约、Producer/Consumer协议与
  紧急处理机制，是所有后续规范的母法。
- **SPEC_ACA_L1_CHARTER.md**：L1-STREAMLINED执行宪章，强调快速交付、4-6项质量门禁、
  TraceDepth=1 与 ≥95%通过阈值，约束轻量项目的最低标准。
- **SPEC_ACA_L2_CHARTER.md**：L2-BALANCED执行宪章，扩展至Function Point追溯、协作节点
  与并行控制，平衡效率与标准化。
- **SPEC_ACA_L3_CHARTER.md**：L3-RIGOROUS执行宪章，引入ADR、INVEST评估、WBS与关键路径，
  支撑高合规项目的严谨审计链。
- **SPEC_ARTIFACT_NAMING_CORE_CONCEPTS.md**：命名体系核心公理，规定Canonical位置、命名
  粒度、版本标签与追溯字段。
- **SPEC_ARTIFACT_NAMING_L1_AUTHORITY.md**：L1命名权威清单，列出各Stage的必备文件名、
  前缀与最小追溯字段。
- **SPEC_ARTIFACT_NAMING_L2_AUTHORITY.md**：L2命名权威，增加Function Point、Task Sequence、
  value_path映射等命名规则。
- **SPEC_ARTIFACT_NAMING_L3_AUTHORITY.md**：L3命名权威，覆盖ADR、审计矩阵、关键路径与
  Blocker档案等高严谨资产。

## 建议阅读路径
1. 先通读 `SPEC_ACA_CORE_PRINCIPLES.md`，掌握宪法级不变量。
2. 根据项目目标选择 L1/L2/L3 宪章，明确约束梯度。
3. 最后对照对应等级的命名权威文档，确保产出与Canonical命名保持一致。
