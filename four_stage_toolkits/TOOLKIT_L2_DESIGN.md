   ```markdown
   - **表现层**: 用户界面和API网关
   - **业务层**: 核心业务逻辑和服务
   ```

2. **技术选型决策记录**
   ```markdown
   ## ADR-001: [技术选择标题]
   
   **状态**: 提议中/已接受/已弃用
   **决策者**: [团队角色]
   **决策日期**: [YYYY-MM-DD]
   
   ### 背景和问题
   [技术选择的背景和需要解决的问题]

   [选择的方案和理由]
   ```

         summary: 获取用户列表

           - name: page
             in: query

               type: integer

## 📋 4. L2-BALANCED关键特征

### 标准化架构管理
- **架构系统性**：完整架构图和组件关系，ADR决策记录
- **接口标准化**：API设计规范，数据模型定义清楚
- **技术决策可追溯**：重要决策有依据，备选方案评估
- **团队协作支持**：设计文档多人协作，知识传承机制

### 与L1/L3差异化
- **L1-STREAMLINED**：基础架构设计（快速迭代）
- **L2-BALANCED**：标准化架构管理（决策可追溯）
- **L3-RIGOROUS**：4+1视图+合规（企业级架构）
