### 扫描检查项目（L1-STREAMLINED级别）

#### 🔴 阻塞性问题（必须修复）
1. **GOAL 清单缺失**：task_planning 目录下是否存在 GOAL 清单文档（参考 CRAFT 中 `[goal_breakdown]` 占位符）
2. **GOAL 前置信息缺失**：GOAL 是否具备 `id/sn/source_vs/related_sc`（可选 `related_seq/context_refs`）
3. **核心文档缺失**：`spec/task_planning/` 是否包含 `task_breakdown.md`、`task_sequence.md` 等关键文档
4. **任务列表缺失**：是否存在可执行的任务分解与待办清单
5. **优先级不明确**：核心任务是否标注优先级或排序依据
6. **工作量评估明显不合理**：评估缺失或与任务规模严重不符
7. **GOAL缺失测试资产驱动**：GOAL是否缺少`test_assets_checklist`字段或与`related_sc`不一致

#### 🟡 警告问题（建议关注）
1. **任务粒度不均**：任务分解粒度差异过大
2. **依赖关系不足**：任务间依赖描述模糊
3. **风险识别不足**：关键风险与缓解措施缺失

#### 🟢 建议优化（L1可跳过）
1. **高级项目管理机制**：复杂的项目管理工具或仪表盘
2. **深入风险分析**：详细的风险量化与应对计划
3. **团队协作优化**：高级协作流程或绩效机制

### 输出格式


### L1修复范围（最小可行任务规划）

#### ✅ 会修复的问题
1. **补齐基础任务文档**：根据 `CRAFT_L1_TASK_PLANNING.md` 中的核心占位符（如 GOAL 清单、任务分解、任务序列）创建/更新相应文档，名称以项目既定命名为准
2. **补足 GOAL 信息**：为重点 GOAL 填写必需字段，确保可追溯
3. **生成可执行的任务清单**：列出核心任务、优先级、简要工作量等级
4. **修正明显不合理的工作量评估**：给出最小可行的迭代/里程碑安排
5. **补足GOAL的测试资产关联**：为GOAL添加`test_assets_checklist`字段，确保与VS测试资产的清晰关联

#### ❌ 不会修复的问题（L1级别跳过）
1. **高级项目管理框架**：复杂工具或大规模协作机制
2. **深入风险控制计划**：细化的风险量化或预算
3. **企业级治理流程**：审批、绩效等复杂流程

### 修复执行流程
1. **确认问题**：基于 >>task_scan_l1 的扫描结果
2. **筛选阻塞项**：仅处理 🔴 级问题  
3. **执行MVP修复**：保证任务规划“可执行、可跟踪”
4. **避免过度规划**：保持轻量，聚焦核心任务

## 工具执行约束

### L1-STREAMLINED原则
- **输入灵活**：可接受目录或文件作为上下文
- **问题优先级**：聚焦 🔴 阻塞性问题，忽略 🟡/🟢
- **修复深度**：确保任务规划“基本可执行”即可
- **容错性**：允许不完美，优先落地与效率

### 防绕过约束
- **禁止智能扩展**：不得添加本工具未定义的扫描项
- **禁止扩展功能**：严格执行 >>task_scan_l1、>>task_fix_l1 定义
- **禁止生成真实管理工具数据**：仅维护文档内容
- **强制模板**：输出必须符合既定格式

### 错误处理
若遇到以下情况需立即声明无法处理：
1. **超出 L1 能力范围**（需复杂项目管理）
2. **关键信息缺失**（GOAL、里程碑等未确认）
3. **跨阶段依赖未完成**（需先回 Stage 1/2/3）
4. **质量门禁冲突**（与上游文档不一致）
